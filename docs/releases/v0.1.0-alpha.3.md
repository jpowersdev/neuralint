# neuralint v0.1.0-alpha.3

This alpha improves semantic-check localization and evidence packing, adds local syntax evidence, and introduces a rule-quality doctor with optional Astra explanations.

## Highlights

- Replace hunk-level model localization with deterministic changed spans and stable coordinate-derived IDs.
- Enforce Jev's aggregate and longest-question limits with conservative dual-budget, shared-resource packing and deterministic split-on-limit fallback.
- Parse complete supported files locally with bundled Tree-sitter grammars, then transmit only bounded enclosing scopes and associated comments.
- Add `neuralint rules doctor --rule RULE_ID` with deterministic validation and a fixed Jev quality matrix.
- Add optional `rules doctor --explain` through `@jpowersdev/effect-pi`, using GPT-6 Astra with tools and repository resource discovery disabled.
- Report actual Astra input tokens, output tokens, and cost without allowing generated output to modify active policy.
- Upgrade the runtime requirement to Node.js 26 and Effect `4.0.0-rc.116`.
- Publish declaration files and a package-root library export.

## Usage

```sh
npm install --global neuralint@alpha
cd /path/to/repository
neuralint init --base origin/main
neuralint rules validate
neuralint check
```

Diagnose a repository rule without invoking a general model:

```sh
neuralint rules doctor --rule EXAMPLE_NO_SECRET_LOGGING
```

Optionally add a concise Astra explanation when Jev reports concerns:

```sh
neuralint rules doctor \
  --rule EXAMPLE_NO_SECRET_LOGGING \
  --source AGENTS.md \
  --explain
```

## Benchmark evidence

The retained 30-rule × 30-span production matrix made 900 decisions in four Jev requests, completed in 1.565 seconds, retained all 30 expected primary findings as definitive, and cost an estimated $0.00864. The corpus remains positive-heavy and is not a production precision estimate.

A controlled doctor corpus contains four good, four defective, four ambiguous, and four evidence-infeasible rules, with 128 human-labeled check outcomes. Across three evaluations per rule, the current 45% advisory threshold achieved 92% rule-level precision and 100% recall. The 75% failure threshold did not cleanly separate clear defects from ambiguous rules and remains provisional.

Focused Astra validation covered a clean rule, a deliberately underspecified rule, and a nuanced Bun evidence-feasibility case. Astra was skipped for the clean rule and correctly distinguished the Bun evidence-planner limitation from a missing organizational-policy decision. The two explanation calls cost $0.02156 in total.

## Known limitations

- Normal Git checks compare committed `base...HEAD`; staged and unstaged working-tree changes are not included yet.
- `--stdin` is available for proposed source, but complete editor-buffer changed-range support is still planned.
- Related-definition and repository retrieval are not implemented.
- Doctor thresholds are based on a small controlled corpus and require independently authored, blinded calibration.
- `rules doctor --explain` requires compatible Pi credentials and model access and incurs provider cost.
- The alpha does not redact source evidence or provide local inference. Confirm that configured endpoints are approved before sending proprietary code.
- Rule, report, and library APIs may change before 1.0.
